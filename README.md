# Nutri-Oedor 🥗

Guia alimentar interativo para pacientes com dor crônica.

## 📋 Descrição

Nutri-Oedor é um aplicativo web educativo que fornece orientações sobre nutrição e alimentação para pessoas com dor crônica. O guia aborda:

- Por que a alimentação importa na dor crônica
- A conexão entre intestino e cérebro
- Composição ideal do prato
- Importância de proteína e fibras
- O que reduzir no dia a dia
- Rotina de sono, água e movimento
- Plano prático de 7 dias
- Guias específicos por tipo de dor
- Quiz final para fixar conhecimento
- Resumo para impressão

## 🚀 Deploy

Este projeto está configurado para deploy automático no **Vercel**:

1. Acesse [vercel.com](https://vercel.com/new)
2. Conecte seu repositório GitHub
3. Clique em "Deploy"

## 💻 Desenvolvimento Local

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

Abra [http://localhost:5173](http://localhost:5173) no navegador.

## 🛠 Tecnologias
